# Image2PDF

A simple and modern Image to PDF Converter built with HTML, CSS, and JavaScript.

## Features

- Convert multiple images into PDF
- Supports JPG, PNG, JPEG, and WEBP
- Image preview
- PDF page size options
- Portrait and landscape modes
- Adjustable image quality
- Download PDF instantly
- No server required

## Technologies

- HTML5
- CSS3
- JavaScript
- jsPDF

## How to Use

1. Upload your images.
2. Arrange or remove images if needed.
3. Select PDF settings.
4. Click "Convert to PDF".
5. Download your PDF.
